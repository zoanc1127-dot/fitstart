# FitStart 中文健身动作查询网站

**FitStart** 是一个专为中文健身初学者打造的轻量级、现代、专业且响应式的健身动作查询与新手引导网站。

## 🌟 核心特性
- **纯前端架构**：无需后端服务器，零配置即可运行。
- **双语智能搜索与复合筛选**：支持按中文/英文名称、身体部位、器械（含“无器械”模式）同时筛选。
- **健身小白友好**：提供动作步骤、常见错误、安全提示及新手入门指南。
- **100% 版权合规**：不依赖任何受版权保护的外部图片或 GIF，采用纯 CSS 科技风占位。
- **开箱即用部署**：完美支持 GitHub Pages 和 Cloudflare Pages。

---

## 🚀 零基础快速运行指南

由于现代浏览器出于安全策略（CORS）限制直接双击 `index.html` 往往无法通过 `fetch` 读取本地 JSON 文件，建议通过以下任一方式运行：

### 方法一：使用 VS Code 的 Live Server 插件（最推荐）
1. 用 Visual Studio Code 打开整个 `fitstart` 项目文件夹。
2. 安装 **Live Server** 插件。
3. 右键点击 `index.html`，选择 **"Open with Live Server"** 即可在浏览器中完美浏览。

### 方法二：使用 Python 简易服务器
如果你电脑安装了 Python，在项目根目录下打开终端/命令行运行：
```bash
python -m http.server 8000
